# 保護者会 日程作成ツール

保護者の希望調査（Microsoft Forms の書き出しExcel）から個人懇談の日程を自動で作り、
担任が手直しして、名前と日時を差し込んだ配布物（Word）まで作るツールです。

- **使うファイルは1つだけ**：`dist/保護者会日程作成ツール.html` を校内の共有フォルダに置き、Edge か Chrome で開きます。
- インストールは不要です。処理はすべてパソコンの中で行い、データはインターネットに送りません。

## 流れ

1. **担当者**（「①担当者」タブ）
   - 全学年の希望調査Excelをまとめて入れる（兄弟姉妹をつなぐため）。
   - 1人あたりの時間、休憩、兄弟姉妹の間隔、担任が出られない時間帯を設定する。
   - 照合できなかった兄弟姉妹を確認し、「日程案を作成する」を押す。
   - 学級ごとの `日程案_〇年〇組.xlsx` を共有フォルダに保存する。
2. **担任**（「②担任」タブ）
   - 自分の学級の日程案を開き、名前をクリック → 移したい枠をクリック（ドラッグも可）で入れ替える。
   - 「保存する」を押す。
   - 配布物のWordを選んで「配布物を作る」を押す（1人1ページ）。

## 自動割り当ての決まり

- ×のついた時間帯には入れない（「いつでもよい」でも×があれば×を優先）。
- 兄弟姉妹は、同じ日の続きの時間（または1枠あけて）になるように最初に割り振る。
- 次に、選べる時間が少ない家庭から順に割り振る（各日の人数をそろえる／早い日から詰める）。
- 同じ生徒の回答が2件あるときは、後から送信された回答を使う。
- 入らない家庭は「未割当」に入れ、担任が手で入れる。未提出者は割り振らない。

## 希望調査フォームの形

次の質問があれば読み取れます（質問の文言は多少違っても大丈夫です）。

| 質問 | 形式 |
|---|---|
| お子様の学級 | 選択（A〜E など） |
| お子様の出席番号 | 選択 |
| お子様の名前 | 記述 |
| 懇談の希望日時について（いつでもよい／都合の悪い日時がある） | 選択 |
| `11月10日(火)13:30～14:30` などの時間帯 | 都合が悪い時間帯に × |
| 兄弟姉妹がいる場合は、学年・組・名前を入力してください。 | 記述 |

兄弟姉妹欄は「2年B組 山田花子」「２－Ｂ 山田」「山田花子（2年2組）」などの書き方のゆれに対応しています。
照合できないものは担当者の画面に出るので、手で相手を選べます。

## 配布物の目印

Wordの中の次の目印を置き換えます：
`【氏名】` `【学年】` `【組】` `【番号】` `【日時】` `【月日】` `【曜日】` `【時刻】` `【終了時刻】`

見本：`demo/配布物テンプレート_見本.docx`

## デモデータ

`demo/` に架空の2年・3年のデータがあります（`python3 demo/make_demo.py` で作り直せます）。

## 開発

```
npm install
npm test        # 計算ロジックのテスト
npm run build   # src/ から dist/保護者会日程作成ツール.html を作る
```
