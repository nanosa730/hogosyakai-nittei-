    4日程案を作る

    1自分の学級の日程案を開く

    担当者が作った「日程案_〇年〇組.xlsx」を開きます。

    2日程の確認・修正

    動かし方：名前をクリックして選び、移したい枠をクリック（ドラッグでもできます）。入っている枠に移すと入れ替わります。

    未割当（ここに移すと日程から外れます）

    3配布物（Word）を作る

    配布物のWordで、名前や日時を入れたい場所に下の目印を書いておき、そのWordを選んでください。1人1ページで全員分が入ったWordができます。

    目印入る内容（例）
    【氏名】生徒の名前
    【学年】【組】【番号】3 / A / 5
    【日時】11月10日（火）13:30～13:40
    【月日】【曜日】【時刻】【終了時刻】11月10日 / 火 / 13:30 / 13:40

    全体の流れ

    1. 担当者：全学年のFormsのExcelを入れて「日程案を作成する」→ 学級ごとのExcel（日程案_〇年〇組.xlsx）を共有フォルダに保存。
    2. 担任：このページの「②担任」で自分の学級の日程案を開き、必要なら順番を入れ替えて「保存する」。
    3. 担任：配布物のWordを選んで「配布物を作る」→ できたWordを確認して印刷。

    自動で割り振るときの決まり

    • ×のついた時間帯には入れません。「いつでもよい」を選んでいても×があれば×を優先します。
    • 兄弟姉妹は、同じ日の続きの時間（または1枠あけて）になるように最初に割り振ります。
    • 次に、×が多く選べる時間が少ない家庭から順に割り振ります。
    • 同じ生徒の回答が2件あるときは、後から送信された回答を使います。
    • 入りきらない家庭は「未割当」に入ります。担任が手で入れてください。

    Excelで直接直してもよい

    日程案のExcelの「日程」シートで、名前と出席番号の行を入れ替えて保存しても大丈夫です。もう一度このページで開くと、×の時間に入っていないかなどをチェックします。

    兄弟姉妹の時間を動かしたとき

    兄弟姉妹のいる家庭を動かすと注意が出ます。相手の学級の担任に連絡してください。
