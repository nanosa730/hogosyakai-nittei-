    1自分の学級の日程案を開く

    担当者が作った「日程案_〇年〇組.xlsx」を開きます。

    2日程の確認・修正

    動かし方：名前をクリックして選び、移したい枠をクリック（ドラッグでもできます）。入っている枠に移すと入れ替わります。
    枠・休憩の増減：時刻（13:30▾など）をクリックすると「上に枠」「上に休憩」「削除」が出ます。足すと下の枠が後ろに、消すと前にずれます。各日の下の「＋最後に枠」「＋最後に休憩」でも足せます。

    未割当（ここに移すと日程から外れます）

    3配布物を印刷する

    日時が決まった生徒全員分を、1人1枚（A4）で印刷します。

    文面を直す（この学級だけ）
    自分で用意したWordに差し込む（上級者向け）

    Wordで、名前や日時を入れたい場所に下の目印を書いておき、そのWordを選んでください。1人1ページで全員分が入ったWordができます。

    目印入る内容（例）
    【氏名】生徒の名前
    【学年】【組】【番号】3 / A / 5
    【日時】11月10日（火）13:30～13:40
    【月日】【曜日】【時刻】【終了時刻】11月10日 / 火 / 13:30 / 13:40

    全体の流れ

    1. 担当者：全学年のFormsのExcelを入れて「日程案を作成する」→ 学級ごとのExcel（日程案_〇年〇組.xlsx）を共有フォルダに保存。
    2. 担任：このページの「②担任」で自分の学級の日程案を開き、必要なら順番を入れ替えて「保存する」。
    3. 担任：「配布物を印刷する」で、1人1枚のお知らせを印刷。

    自動で割り振るときの決まり

    • ×のついた時間帯には入れません。「いつでもよい」を選んでいても×があれば×を優先します。
    • 兄弟姉妹は、同じ日の続きの時間（または1枠あけて）になるように最初に割り振ります。
    • 次に、×が多く選べる時間が少ない家庭から順に割り振ります。
    • 同じ生徒の回答が2件あるときは、後から送信された回答を使います。
    • 入りきらない家庭は「未割当」に入ります。担任が手で入れてください。

    Excelで直接直してもよい

    日程案のExcelの「日程」シートで、名前と出席番号の行を入れ替えて保存しても大丈夫です。もう一度このページで開くと、×の時間に入っていないかなどをチェックします。

    面談枠や休憩を足したり消したりしたとき

    下の枠の時刻がずれます。ずれた結果、保護者が×を付けた時間帯に入ると赤で「直してください」、希望調査の時間帯の外に出ると「確認してください」と出ます。開いたときから時刻が変わった家庭には「時刻変更」の印が付きます。

    学級の日程表（A4・1枚）

    担任は「日程表を印刷（A4・1枚）」で、5日分の面談予定を1枚に印刷できます。担当者は日程案を作ったあと「全学級の日程表を印刷」で、全学級分（1学級1枚）をまとめて印刷できます。

    配布物の文面を変えたいとき

    担当者は「①担当者」の「5 配布物の文面」で、全学級共通の文面（時候のあいさつ、持ち物など）を直せます。担任は「3 配布物を印刷する」の「文面を直す」で、自分の学級だけ直せます（日程案を保存すると一緒に保存されます）。

    兄弟姉妹の時間を動かしたとき

    兄弟姉妹のいる家庭を動かすと注意が出ます。相手の学級の担任に連絡してください。
